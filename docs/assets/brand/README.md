# NortPole brand assets

The mark is the **North Star**: a four-point guiding star on a 24×24 grid, one colour, so it follows the theme
(decision 0007). Concept sketches; a designer may refine proportions and the brand colour before launch.

| File | Use |
|---|---|
| `mark.svg` | The mark alone (uses `currentColor`) |
| `logotype.png`, `logotype-dark.png` | Mark with the NortPole wordmark, for light and dark backgrounds (2640×733) |
| `app-icon-512.png` | App icon: white star on navy `#1f2a44`, rounded square |
| `social-preview.png` | GitHub social preview (1280×640): upload in the repository's Settings, General, Social preview |

In the product: `apps/workspace/lib/opal/src/logos/nortpole-logo.tsx` (sidebar and home), `apps/workspace/public/`
(`nortpole.ico` favicon at 16, 32 and 48 px, `apple-touch-icon.png`, `icon-512.png`, `logo*.png`, `logotype*.png`), and
the Craft web-app template icons.

There is no accent colour; the sign-in sky and glass layers are described in decision 0007.
