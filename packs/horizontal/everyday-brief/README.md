# Evidence brief (horizontal)

Domain-neutral workflows any team can use: a cited brief, finding the policy that covers a question, and comparing two
documents. Runs on local or private routes, needs at least one citation, and never sends anything.

## Evidence Research in Chat

Version 1.1.0 adds **Evidence Research** as a read-only Chat agent. After an administrator installs and activates the signed pack, an agent owner can select **Prepare Chat agent draft** from the pack card. Choose the Knowledge collections in the editor, save the draft, and run **Test in Chat**. **Version history** shows the pack version behind each candidate and release.
